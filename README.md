**Virtual Lab Partner** is an AI-powered academic laboratory companion web platform designed to assist science and engineering students through every stage of their experimental workflow: pre-lab preparation, safety protocols, real-time procedure guidance, observational logging, data computation, and automated lab report drafting.

## ✨ Features & Core Modules

1. **Safety Protocol & PPE Verification**: Interactive checklists and risk assessment for lab safety.
2. **Experimental Procedure Walkthrough**: Step-by-step guidance through chemistry and physics experiments.
3. **Real-time Observation & Data Logger**: Structured logging table for experimental measurements and readings.
4. **Interactive Formula Calculator & Analysis**: Built-in dynamic calculation models with instant error margin computation.
5. **Interactive Charting Suite**: Dynamic data visualization powered by Chart.js.
6. **Automated Lab Report Generator**: Instant report generation structured for academic submission.
7. **Comprehensive Dark Mode UI**: Modern glassmorphic interface with Lucide icons and Tailwind CSS.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Fast, zero-dependency client-side execution.
- **Tailwind CSS**: Modern utility-first styling with responsive design.
- **Lucide Icons**: Clean, consistent vector iconography.
- **Chart.js**: Client-side interactive charting for scientific data plotting.

## 💻 Local Development

You can run this project locally without any complex installation:

### Method 1: Open Directly in Browser
Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).

### Method 2: Local PowerShell Server
Run the included PowerShell server script:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit [http://localhost:8080](http://localhost:8080) in your browser.

## 📦 Deployment Instructions

### Deploy to GitHub Pages (Automatic)

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Virtual Lab Partner"
   git branch -M main
   git remote add origin https://github.com/divyadharshiniv79-source/divya-26.git
   git push -u origin main
   ```

2. Go to your GitHub repository:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch` (Branch: `main`, Folder: `/ (root)`), OR choose `GitHub Actions`.
   - Click **Save**.

Your application will be live at:
`https://divyadharshiniv79-source.github.io/divya-26/`
